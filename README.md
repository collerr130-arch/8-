# Испорченный переводчик (Android)

Приложение переводит введённый текст по цепочке на **случайные языки** — по умолчанию 5 раз подряд
(можно выбрать от 1 до 10). Каждый шаг показывается отдельной карточкой, а в конце текст
по желанию переводится обратно на исходный язык, чтобы было видно, что с ним стало.

## Как получить APK
- **GitHub Actions**: при каждом push запускается workflow «Build APK». Готовый файл лежит
  в артефакте `RandomTranslate-apk` на странице запуска (вкладка *Actions*).
- **Android Studio**: открыть папку проекта → *Run*, или `./gradlew assembleDebug`
  (APK: `app/build/outputs/apk/debug/app-debug.apk`).

## Устройство
- Kotlin, Material 3, корутины; minSdk 24 (Android 7.0).
- Перевод — бесплатный публичный эндпоинт Google Translate (`translate.googleapis.com`, без ключа),
  нужен интернет.
- Языки выбираются из списка в ~45 языков (`Translator.kt`); подряд один и тот же язык не повторяется.
