# Revolver: мод для Blade & Sorcery (PC)

Шестизарядный револьвер с настоящей 3D-моделью.

| Действие | Как |
|---|---|
| Выстрел | Курок (trigger) |
| Перезарядка | Кнопка альтернативного действия или резкий поворот кисти вокруг ствола |
| Пустой барабан | Щелчок |

Выстрел мгновенный (хитскан): красный трассер, вспышка, звук, отдача и вибрация контроллера.
- **Урон:** 35, в голову ×3, в шею ×2.
- **Попадание:** враг теряет равновесие и падает, часть тела получает толчок.
- **Лёгкое автонаведение:** если прицел в пределах 4° от головы или слабой точки, пуля летит в неё.
- **Ближний бой:** рукоятью можно бить.

Все цифры меняются в `Items/Item_Revolver.json`, пересобирать код не нужно.

Мод состоит из двух частей:
1. **Код и настройки:** ставятся одной командой, как HomingThrow.
2. **3D-модель:** собирается один раз в Unity с официальным SDK.

## Часть 2. Модель в Unity

### 2.1. Установка (один раз)
1. **Unity Hub:** скачай с https://unity.com/download и установи.
2. **Unity 2021.3.38f1** (нужна именно эта версия).
   - Самый простой способ: открой в браузере ссылку `unityhub://2021.3.38f1/7a2fa5d8d101`, и Unity Hub сам предложит установку.
   - Или в Unity Hub: Installs → Install Editor → Archive → найди 2021.3.38f1.
   - Дополнительные модули не нужны.
3. **SDK игры:** в PowerShell выполни
   ```powershell
   cd $HOME; git clone https://dev.azure.com/Warpfrog/BasSDK/_git/BasSDK
   ```
4. **Открой SDK:** Unity Hub → Projects → Add → Add project from disk → папка `BasSDK`. Первое открытие идёт 10–30 минут, это нормально.

### 2.2. Модель револьвера
1. Найди бесплатную модель на https://sketchfab.com: поиск `revolver`, фильтр **Downloadable**. Скачай в формате **FBX**. Лучше брать модель low-poly, до ~20 тысяч треугольников.
2. В Unity, в окне **Project** внизу, создай папку `Assets/Revolver` (правый клик → Create → Folder). Перетащи туда FBX и текстуры.

### 2.3. Префаб из примера ProtoGun
Пример ProtoGun уже содержит рукоять, коллайдеры и точку выстрела, поэтому собираем револьвер из него.

1. **Скопируй пример.** В Project открой `Assets/SDK/Examples/Items`, выбери **ProtoGun**, нажми **Ctrl+D**.
2. **Назови копию.** Перетащи её в `Assets/Revolver` и переименуй в **Revolver**.
3. **Открой префаб** двойным кликом. Слева, в окне **Hierarchy**, видна его структура.
4. **Корневой объект Revolver:**
   - В **Inspector** справа, в компоненте **Item**, поле **Item Id** = `Revolver`.
   - Компонент **AIFireable** удали: ⋮ → Remove Component.
5. **Модель.** Перетащи свою модель из Project внутрь объекта **Mesh** в Hierarchy. Инструментами Move, Rotate и Scale (клавиши W, E, R) поставь её так:
   - ствол смотрит вдоль **синей стрелки (Z)** корневого объекта;
   - размер реальный, около 25–30 см в длину. Ориентир — серые кубики ProtoGun.
6. **Кубики-заглушки Cube и Cylinder внутри Mesh:**
   - на каждом сними галочку у **Mesh Renderer**, чтобы они стали невидимыми;
   - их коллайдеры оставь;
   - подгони размер и позицию этих коллайдеров под модель: Cube — по корпусу и стволу, Cylinder — по рукояти.
7. **Handle** — место, где рука держит револьвер. Перемести его на рукоять. Его дочерние **OrientRight**/**OrientLeft** определяют, как ладонь обхватывает рукоять; поверни их, если в игре хват выглядит криво.
8. **BottomHandle** перемести на низ рукояти. Это второй хват.
9. **Aim** — точка вылета пули. Поставь её на **конец ствола**, синей стрелкой вперёд. Можно переименовать в `Muzzle`, но это не обязательно.
10. **Барабан (по желанию).** Если в модели барабан — отдельная часть, переименуй её в `Drum`, и он будет проворачиваться на 60° при каждом выстреле.
11. **Сохрани:** Ctrl+S, затем выйди из префаба стрелкой «<» в Hierarchy.

### 2.4. Addressables
Игра находит модель по адресу `Danil.Revolver`.

1. Выбери префаб **Revolver** в Project. В Inspector сверху поставь галочку **Addressable**, а в поле рядом впиши `Danil.Revolver`.
2. Открой Window → Asset Management → Addressables → **Groups**.
   - Создай группу: Create → Group → **Packed Assets** и переименуй её в `Revolver`.
   - Перетащи `Danil.Revolver` из группы, где он оказался, в группу **Revolver**.
3. Открой меню **ThunderRoad (SDK) → Asset Bundle Builder**.
   - Нажми **Create New Asset Group**, введи имя `Revolver` и нажми OK.
   - В Project открой `Assets/Personal/AssetBundleGroups/Revolver`. В Inspector, в список **Addressable Asset Groups**, добавь группу **Revolver** из пункта 2.

### 2.5. Сборка и экспорт
1. В **Asset Bundle Builder**:
   - **Game executable path:** укажи `BladeAndSorcery.exe` из папки игры.
   - Нажми **Windows** в «Set build mode».
   - Отметь галочкой только группу **Revolver**, включи «Export After Build».
   - **Не включай «Clean destination»**, иначе экспорт удалит код мода.
2. Нажми **Build**. Бандл экспортируется в `...\StreamingAssets\Mods\Revolver`.
3. **Ещё раз выполни Часть 1** (`install.ps1`). Скрипт вернёт на место `manifest.json` и json предмета, если экспорт их перезаписал.
4. **Запусти игру:** книга предметов → вкладка **Daggers** → **Revolver**.

## Если что-то не так
| Проблема | Что сделать |
|---|---|
| Револьвера нет в книге | Проверь, что адрес в Addressable ровно `Danil.Revolver`, а Item Id = `Revolver`. |
| Стреляет вбок или назад | Поверни **Aim** так, чтобы синяя стрелка смотрела вдоль ствола. |
| Рука держит криво | Поверни **Handle** / **OrientRight** в префабе и пересобери (п. 2.5). |
| Нет трассера | Отключи `redTracer` в json, остальное работает. |
| Перезарядка срабатывает сама | Увеличь `flickReloadSpeed` в json, например до 20. |
| Слишком сильный или слабый | `damage`, `headshotMultiplier`, `recoilAngle` в json. |
